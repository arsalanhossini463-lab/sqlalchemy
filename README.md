# SQLAlchemy Practice Projects

A set of small Python scripts for learning **SQLAlchemy ORM** with a **SQLite** database. The scripts go from basic CRUD operations to table relationships.

## Files

| File | Description | Database |
|------|-------------|----------|
| `app_1.py` | Basic CRUD on two separate tables (`Car`, `Customer`): create, read, filter (`filter_by`, `filter`, `like`), update, delete | `CarData.db` |
| `app_2.py` | One-to-many relationship between `Customer` and `Car` using `ForeignKey` and `relationship` | `CarData_relation.db` |
| `app_3.py` | Same as `app_2.py`, plus a `Student` table with CRUD functions (`add_student`, `get_all_students`, `update_student`, `delete_student`) | `CarData_relation.db` |
| `app_4.py` | `Student` and `Course` tables with a relationship and `cascade="all, delete"` | `University.db` |

## Requirements

- Python 3.8 or newer
- SQLAlchemy 2.x

Install the dependency:

```bash
pip install -r requirements.txt
```

## How to run

```bash
python app_1.py
python app_2.py
python app_3.py
python app_4.py
```

The SQLite database file is created automatically the first time you run a script.

## Important notes

- Most of the insert and query examples are **commented out**. On the first run, uncomment the block that adds data (for example the `customer1`, `car1` lines) so the tables have records, then run the script.
- Some scripts print values from a record (such as `car1.brand`). If the table is empty, they will raise an error, so add the data first.
- `app_1.py` deletes the first car whose model matches `%g%` every time it runs. Comment those lines out if you do not want that.
- The `.db` files are generated by the scripts and are not included in the repository (see `.gitignore`).

## Concepts covered

- Creating an engine and a session
- Defining models with `declarative_base`
- Insert, query, update and delete
- Filtering with `filter_by`, `filter`, and `like`
- One-to-many relationships with `ForeignKey` and `relationship(back_populates=...)`
- Cascade delete
